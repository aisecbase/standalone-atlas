Злоумышленник может создавать вредоносные промпты и подавать их на вход LLM, заставляя модель действовать непредусмотренным образом.

Такие «промпт-инъекции» часто предназначены для того, чтобы модель игнорировала отдельные элементы исходных инструкций и вместо этого следовала инструкциям злоумышленника.

Промпт-инъекции могут служить вектором первичного доступа к LLM, предоставляя злоумышленнику точку закрепления для выполнения последующих этапов операции.

Они могут быть предназначены для обхода защитных механизмов LLM или для предоставления злоумышленнику возможности отдавать привилегированные команды.

Последствия промпт-инъекции могут сохраняться на протяжении всей интерактивной сессии с LLM.

Злоумышленник может внедрять вредоносные промпты напрямую ([прямая промпт-инъекция](/techniques/AML.T0051.000)), чтобы использовать LLM для генерации вредоносного содержимого либо закрепиться в системе и вызвать дальнейшие последствия.

Промпты также могут внедряться косвенно, когда LLM в ходе штатной работы принимает на обработку вредоносный промпт из другого источника данных ([косвенная промпт-инъекция](/techniques/AML.T0051.001)). Злоумышленник может использовать этот тип инъекции, чтобы закрепиться в системе или нацелить атаку на пользователя LLM.

Вредоносные промпты могут также активироваться действиями пользователя или системными событиями ([триггерная промпт-инъекция](/techniques/AML.T0051.002)).
