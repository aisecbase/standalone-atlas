Этот сайт — неофициальный русский перевод MITRE ATLAS, созданный и поддерживаемый проектом [aisecbase.ru](https://aisecbase.ru/).

Цель проекта — сделать основные материалы ATLAS удобнее для русскоязычных специалистов: аналитиков, инженеров безопасности, red team, blue team и команд, которые работают с рисками AI/ML-систем.

## Как прислать перевод

Переводы принимаются через запрос на изменение в [репозиторий](https://github.com/aisecbase/standalone-atlas) этой русской версии. Чаще всего это не отдельный Markdown-файл, а изменение переводческого слоя в YAML или правка уже существующего перевода.

Для перевода объектов ATLAS используется `data/translations/ru.yaml`: туда добавляются русские названия, описания, summary и процедуры по ID техник, тактик, мер защиты и кейсов. На основе этого файла генератор пересобирает объектные страницы в `content/`, отчеты покрытия и `data/generated/atlas.yaml`; сгенерированные страницы вручную обычно не правятся.

Статические материалы раздела «Ресурсы» лежат в `content/resources/*.md` и переводятся как обычные Markdown-страницы.

Для других языков можно добавить отдельный переводческий слой, например `data/translations/es.yaml`, и собрать объектные страницы с ним:

```bash
ATLAS_LANG=es go run ./cmd/atlasgen
hugo --minify
```

Если файл перевода лежит в другом месте, используйте `ATLAS_TRANSLATION_FILE`. Для полноценной локализации также нужно перевести статические страницы, меню и UI-строки сайта. Сейчас переключатель `EN` ведет на официальный англоязычный ATLAS, а не на локальную английскую копию.

Для переведенных описаний можно сохранять `source.description_sha256` или `source.summary_sha256`. Если исходный текст ATLAS изменится в новом релизе, такие объекты попадут в раздел «Требует проверки» на странице покрытия перевода.

Хеш для нужного ID лучше считать через генератор, чтобы не ошибиться с переносами строк в исходном YAML:

```bash
go run ./cmd/atlasgen --source-hash AML.TA0000
```

Команда выведет готовый фрагмент `source:`, который можно вставить в перевод этого объекта.

Перед отправкой изменений желательно собрать сайт локально:

```bash
hugo --minify
```

Если менялись переводы объектов ATLAS, сначала нужно пересобрать сгенерированные страницы:

```bash
go run ./cmd/atlasgen
hugo --minify
```

Изменения в саму базу знаний ATLAS — новые техники, кейсы, исправления смысла оригинальных данных — следует отправлять в официальный проект MITRE ATLAS: [Contribute to ATLAS](https://atlas.mitre.org/contribute).
